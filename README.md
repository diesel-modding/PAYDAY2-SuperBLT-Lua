# Payday 2 SuperBLT

An open source Lua hook for Payday 2, designed and created for ease of use for both players and modders.  
This repository is for the Lua base that controls and loads mods into Payday 2, and the options and save files associated with the BLT. The DLL hook code can be found in it's own [repository](https://github.com/diesel-modding/PAYDAY2-SuperBLT).

## Download

Visit https://modworkshop.net/mod/58342 to get the latest stable download.
